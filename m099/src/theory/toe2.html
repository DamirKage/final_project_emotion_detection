2. Бір фазалы синусоидалы ток тізбектері

Тестте: 5 сұрақ2 A + 3 B

Розеткадағы кернеу тұрақты емес, ол синус заңымен секундына 50 рет тербеледі. Бұл тақырыпта осындай токты сипаттайтын шамаларды, үш элементтің (R, L, C) оған қалай жауап беретінін, комплекс сандармен есептеуді, қуаттарды, резонансты және магнит өрісі арқылы байланысқан орауыштарды үйренесің. Тестте көбіне бір-екі формуламен шығатын сандық есептер мен фазалық қатынастар сұралады.

IT тілімен

Синусоида деген үш параметрі бар сигнал: амплитуда, жиілік, фаза. Жиілік барлық жерде бірдей (50 Гц) болғандықтан, әр сигналды екі санмен ғана сақтауға болады: ұзындық пен бұрыш. Бұл дегеніміз комплекс сан. Сонда дифференциалдық теңдеулердің орнына кәдімгі Ом заңын комплекс сандармен жазасың. Бүкіл тақырыптың идеясы осы.

2.1. Синусоидалы шама және оның параметрлері

Синусоидалы ток уақыт бойынша синус заңымен өзгереді. Кез келген уақыттағы мәні лездік мән деп аталады және кіші әріппен жазылады: \(i\), \(u\), \(e\).

\[ i = I_m \sin(\omega t + \psi_i),\qquad u = U_m \sin(\omega t + \psi_u) \]
  • \(I_m,\ U_m\): амплитуда, ең үлкен мән (А, В).
  • \(T\): период, бір толық тербелістің уақыты (с).
  • \(f = 1/T\): жиілік, секундтағы тербеліс саны (Гц). Қазақстан желісінде \(f = 50\) Гц, \(T = 0{,}02\) с.
  • \(\omega = 2\pi f = 2\pi/T\): бұрыштық жиілік (рад/с). 50 Гц үшін \(\omega = 314\) рад/с.
  • \(\omega t + \psi\): фаза, синустың аргументі. \(\psi\): бастапқы фаза, \(t = 0\) сәтіндегі фаза (градус не радиан).
Мысал 1. Өрнектен параметрлерді оқу

\(u = 311\sin(314t + 30^\circ)\) В берілген.

  1. Амплитуда: \(U_m = 311\) В.
  2. Бұрыштық жиілік: \(\omega = 314\) рад/с. Жиілік: \(f = \omega/(2\pi) = 314/6{,}28 = 50\) Гц.
  3. Период: \(T = 1/f = 0{,}02\) с.
  4. Бастапқы фаза: \(\psi_u = 30^\circ\). \(t=0\) сәтінде \(u = 311\cdot\sin 30^\circ = 155{,}5\) В.

Фаза ығысуы

Жиілігі бірдей екі синусоиданың бір-біріне қатысты ығысуын фаза ығысуы дейді. Электр техникасында \(\varphi\) әрпімен кернеу мен токтың арасындағы ығысу белгіленеді:

\[ \varphi = \psi_u - \psi_i \]
  • \(\varphi \gt 0\): кернеу токтан озады (ток қалады). Индуктивтік сипат.
  • \(\varphi \lt 0\): ток кернеуден озады. Сыйымдылықтық сипат.
  • \(\varphi = 0\): фазалас. \(\varphi = \pm 180^\circ\): қарсы фазада.
Тесттегі тұзақ

Графикте «оң жақтағы қисық озады» деп ойлама. Уақыт осінде сол жақтағысы ертерек болады, демек сол озады. Тағы бір тұзақ: \(\varphi\) әрқашан «кернеу минус ток», керісінше емес.

2.2. Әсерлік және орташа мән

Лездік мән үнемі өзгереді, сондықтан айнымалы токты бір санмен сипаттау үшін әсерлік мән қолданылады. Бұл резисторда дәл сондай жылу бөлетін тұрақты токтың мәні. Математикада бұл период бойынша орташа квадраттық мән (RMS).

\[ I = \sqrt{\frac{1}{T}\int_0^T i^2\,dt} = \frac{I_m}{\sqrt2} = 0{,}707\,I_m,\qquad U = \frac{U_m}{\sqrt2} \]

Әсерлік мән индексі жоқ бас әріппен жазылады: \(I\), \(U\), \(E\). Вольтметр мен амперметр әсерлік мәнді көрсетеді. «220 В» деген әсерлік мән, амплитудасы \(220\cdot\sqrt2 = 311\) В.

Орташа мән. Синусоиданың толық период бойынша орташасы нөл (оң және теріс жарты толқын бірдей). Сондықтан орташа мән деп жарты периодтағы орташаны айтады:

\[ I_{\text{орт}} = \frac{2}{\pi} I_m = 0{,}637\,I_m \]

Қисықтың пішінін екі коэффициент сипаттайды. Синусоида үшін: амплитуда коэффициенті \(k_a = I_m/I = \sqrt2 = 1{,}41\), пішін коэффициенті \(k_{\text{п}} = I/I_{\text{орт}} = \pi/(2\sqrt2) = 1{,}11\).

Мысал 2

Ток \(i = 14{,}1\sin(314t - 30^\circ)\) А. Әсерлік мән: \(I = 14{,}1/1{,}41 = 10\) А. Жарты периодтағы орташа мән: \(I_{\text{орт}} = 0{,}637\cdot 14{,}1 = 9\) А. Амперметр 10 А көрсетеді.

2.3. Айналмалы вектор және векторлық диаграмма

Синусоиданы сызу қиын, қосу одан да қиын. Сондықтан оны айналмалы вектормен алмастырады. Ұзындығы \(I_m\) вектор сағат тіліне қарсы \(\omega\) бұрыштық жылдамдықпен айналады. Оның тік осьтегі проекциясы дәл \(I_m\sin(\omega t + \psi)\) береді. \(t = 0\) сәтінде вектор көлденең осьпен \(\psi\) бұрыш жасайды.

Барлық векторлар бірдей жылдамдықпен айналатындықтан, олардың өзара орналасуы өзгермейді. Сондықтан векторларды \(t=0\) сәтінде «тоқтатып» сызады. Осындай сурет векторлық диаграмма деп аталады. Ондағы ережелер:

  • вектордың ұзындығы әсерлік мән (не амплитуда), масштабпен;
  • бұрыш сағат тіліне қарсы бағытта оң саналады, сол жаққа бұрылған вектор озады;
  • синусоидаларды қосу векторларды геометриялық қосумен алмастырылады.

2.4. Үш идеал элемент: R, L, C

Айнымалы ток тізбегі үш «кірпіштен» құралады. Әрқайсысы токқа өзінше қарсыласады және ток пен кернеудің арасында өз фаза ығысуын жасайды.

Есте сақта

L-де ток «жалқау», кешігеді (индуктивтілік токтың өзгеруіне кедергі жасайды). C-да ток алдымен келіп, кернеуді содан кейін «толтырады». Идеал L мен C активтік қуат тұтынбайды, сондықтан олардың кедергісі реактивтік деп аталады.

2.5. Комплекс сандар: қысқа курс

Жазықтықтағы векторды бір комплекс санмен жазуға болады. Электр техникасында жорамал бірлік \(j\) әрпімен белгіленеді (\(i\) ток үшін бос емес): \(j^2 = -1\).

\[ \underline{A} = a + jb = A e^{j\alpha} = A(\cos\alpha + j\sin\alpha) \]
  • \(a + jb\): алгебралық түр. \(a\) нақты бөлік, \(b\) жорамал бөлік.
  • \(Ae^{j\alpha}\): көрсеткіштік түр. \(A\) модуль (вектор ұзындығы), \(\alpha\) аргумент (бұрыш).
  • Өту: \(A = \sqrt{a^2+b^2}\), \(\alpha = \operatorname{arctg}(b/a)\); кері: \(a = A\cos\alpha\), \(b = A\sin\alpha\).
АмалҚай түрде ыңғайлыЕреже
Қосу, азайтуалгебралықнақты бөліктер бөлек, жорамал бөліктер бөлек
Көбейтукөрсеткіштікмодульдер көбейтіледі, бұрыштар қосылады
Бөлукөрсеткіштікмодульдер бөлінеді, бұрыштар азайтылады
Түйіндес санкез келген\(\overset{*}{A} = a - jb = Ae^{-j\alpha}\)

Пайдалы мәндер: \(j = e^{j90^\circ}\), \(-j = e^{-j90^\circ} = 1/j\), \(-1 = e^{j180^\circ}\). \(j\)-ге көбейту векторды 90° алға (сағат тіліне қарсы), \(-j\)-ге көбейту 90° артқа бұрады.

Мысал 4. Комплекс сандармен амалдар
  1. \(3 + j4\): модуль \(\sqrt{9+16} = 5\), бұрыш \(\operatorname{arctg}(4/3) = 53{,}1^\circ\). Демек \(5e^{j53{,}1^\circ}\).
  2. \(10e^{j30^\circ} = 10\cos30^\circ + j10\sin30^\circ = 8{,}66 + j5\).
  3. Қосу: \((3+j4) + (4-j3) = 7 + j1\).
  4. Көбейту: \(5e^{j53{,}1^\circ}\cdot 5e^{-j36{,}9^\circ} = 25e^{j16{,}2^\circ}\). Тексеру: \((3+j4)(4-j3) = 12 - j9 + j16 + 12 = 24 + j7\), модулі 25.
  5. Бөлу: \(100e^{j0^\circ} / 5e^{j53{,}1^\circ} = 20e^{-j53{,}1^\circ}\).

2.6. Комплекстік (символдық) әдіс

Синусоидалы шаманы оның векторына сәйкес комплекс санмен алмастырамыз. Ол комплекс әсерлік мән деп аталады, үстіне нүкте қойылады:

\[ i = I_m\sin(\omega t + \psi_i)\ \longleftrightarrow\ \dot I = I e^{j\psi_i},\qquad I = \frac{I_m}{\sqrt2} \]

Ең маңыздысы: дифференциалдау \(j\omega\)-ға көбейтуге, интегралдау \(j\omega\)-ға бөлуге айналады. Сондықтан \(u = L\,di/dt\) орнына \(\dot U = j\omega L\,\dot I\) деп жазамыз. Дифференциалдық теңдеулер алгебралық теңдеулерге айналады.

Комплекстік кедергі және өткізгіштік

\[ \underline{Z} = \frac{\dot U}{\dot I} = R + jX = z e^{j\varphi},\qquad z = \sqrt{R^2 + X^2},\quad \varphi = \operatorname{arctg}\frac{X}{R} \]

\(\underline{Z}\): комплекстік кедергі (Ом), \(R\): активтік кедергі, \(X = X_L - X_C\): реактивтік кедергі, \(z\): толық кедергі (модуль), \(\varphi\): кернеу мен токтың фаза ығысуы.

Элемент\(\underline{Z}\)Көрсеткіштік түрі
R\(R\)\(Re^{j0^\circ}\)
L\(j\omega L = jX_L\)\(X_L e^{j90^\circ}\)
C\(\dfrac{1}{j\omega C} = -jX_C\)\(X_C e^{-j90^\circ}\)

Комплекстік өткізгіштік кедергіге кері шама:

\[ \underline{Y} = \frac{1}{\underline{Z}} = g - jb = y e^{-j\varphi},\qquad g = \frac{R}{z^2},\quad b = \frac{X}{z^2},\quad y = \frac1z \]

\(g\): активтік өткізгіштік, \(b = b_L - b_C\): реактивтік өткізгіштік, \(y\): толық өткізгіштік. Бірлігі сименс (См).

Тесттегі тұзақ

Тармақта R мен X тізбектей тұрса, \(g \ne 1/R\). Дұрысы \(g = R/(R^2+X^2)\). Мысалы \(\underline{Z} = 3 + j4\) Ом үшін \(g = 3/25 = 0{,}12\) См, \(b = 4/25 = 0{,}16\) См, ал \(1/3 = 0{,}33\) См қате. \(g = 1/R\) тек таза резисторлық тармақта.

Ом және Кирхгоф заңдары комплекс түрде

\[ \dot I = \frac{\dot U}{\underline{Z}} = \dot U\,\underline{Y};\qquad \sum \dot I_k = 0;\qquad \sum \underline{Z}_k \dot I_k = \sum \dot E_k \]

Тұрақты ток тізбегінің барлық әдістері (тізбектей және параллель қосу, контурлық токтар, түйіндік потенциалдар, баламалы генератор) өзгеріссіз жарайды, тек \(R\) орнына \(\underline{Z}\), сандар орнына комплекстер қойылады. Тізбектей: \(\underline{Z} = \underline{Z}_1 + \underline{Z}_2\). Параллель: \(\underline{Y} = \underline{Y}_1 + \underline{Y}_2\), яғни \(\underline{Z} = \underline{Z}_1\underline{Z}_2/(\underline{Z}_1+\underline{Z}_2)\).

Мысал 5. Ом заңы комплекс түрде

\(\dot U = 100e^{j0^\circ}\) В кернеуге \(R = 30\) Ом мен \(X_L = 40\) Ом тізбектей қосылған.

  1. \(\underline{Z} = 30 + j40 = 50e^{j53{,}1^\circ}\) Ом.
  2. \(\dot I = 100e^{j0^\circ}/50e^{j53{,}1^\circ} = 2e^{-j53{,}1^\circ}\) А \(= 1{,}2 - j1{,}6\) А.
  3. Ток 2 А, кернеуден 53,1° қалады. Лездік мәні: \(i = 2\sqrt2\sin(\omega t - 53{,}1^\circ)\) А.
Тесттегі тұзақ

Кирхгоф заңдары лездік мәндер мен комплекстер үшін орындалады, ал әсерлік мәндердің (аспап көрсетулерінің) арифметикалық қосындысы үшін орындалмайды. Тізбектей тұрған R мен L-дегі 60 В және 80 В кернеулер 140 В емес, \(\sqrt{60^2+80^2} = 100\) В береді.

2.7. R, L, C тізбектей қосылуы

Тізбектей қосылуда барлық элементтен бір ток өтеді, сондықтан диаграмманы ток векторынан бастап саламыз. Кернеулер векторлық түрде қосылады: \(\dot U = \dot U_R + \dot U_L + \dot U_C\).

\[ \underline{Z} = R + j(X_L - X_C),\qquad z = \sqrt{R^2 + (X_L - X_C)^2},\qquad I = \frac{U}{z} \]
\[ U = \sqrt{U_R^2 + (U_L - U_C)^2},\qquad \operatorname{tg}\varphi = \frac{X_L - X_C}{R},\qquad \cos\varphi = \frac{R}{z} \]

\(U_L\) мен \(U_C\) қарама-қарсы бағытталған (бірі токтан 90° озады, екіншісі 90° қалады), сондықтан олар бір-бірін азайтады. Тізбектің сипаты қай реактивтік кедергі үлкен екеніне байланысты:

  • \(X_L \gt X_C\): активтік-индуктивтік сипат, \(\varphi \gt 0\), ток кернеуден қалады;
  • \(X_L \lt X_C\): активтік-сыйымдылықтық сипат, \(\varphi \lt 0\), ток озады;
  • \(X_L = X_C\): кернеулер резонансы, \(\varphi = 0\).
Мысал 6. Тізбектей RLC

\(U = 100\) В, \(R = 30\) Ом, \(X_L = 80\) Ом, \(X_C = 40\) Ом.

  1. \(X = 80 - 40 = 40\) Ом. \(z = \sqrt{30^2 + 40^2} = 50\) Ом.
  2. \(I = 100/50 = 2\) А.
  3. \(U_R = 2\cdot30 = 60\) В, \(U_L = 2\cdot 80 = 160\) В, \(U_C = 2\cdot 40 = 80\) В.
  4. Тексеру: \(U = \sqrt{60^2 + (160-80)^2} = 100\) В.
  5. \(\cos\varphi = 30/50 = 0{,}6\), \(\varphi = +53{,}1^\circ\). Сипаты индуктивтік, ток қалады.

Назар аудар: орауыштағы кернеу (160 В) кірістегі кернеуден (100 В) үлкен. Айнымалы токта бұл қалыпты жағдай.

Кедергілер үшбұрышы кернеулер үшбұрышының барлық қабырғасын токқа бөлгенде шығады: катеттері \(R\) және \(X\), гипотенузасы \(z\). Одан \(R = z\cos\varphi\), \(X = z\sin\varphi\).

Өзіңді тексер: R = 8 Ом, XC = 6 Ом тізбектей. z және сипаты?

z = √(64 + 36) = 10 Ом. X = −6 Ом, φ = −36,9°, сипаты активтік-сыйымдылықтық, ток кернеуден озады. cos φ = 0,8.

2.8. R, L, C параллель қосылуы

Параллель қосылуда барлық тармақта бір кернеу, сондықтан диаграмманы кернеу векторынан бастаймыз. Енді токтар векторлық қосылады: \(\dot I = \dot I_R + \dot I_L + \dot I_C\). Есептеуге кедергі емес, өткізгіштік ыңғайлы.

\[ I_R = Ug,\quad I_L = Ub_L,\quad I_C = Ub_C;\qquad g = \frac1R,\quad b_L = \frac{1}{X_L},\quad b_C = \frac{1}{X_C} \]
\[ I = \sqrt{I_R^2 + (I_L - I_C)^2} = Uy,\qquad y = \sqrt{g^2 + (b_L - b_C)^2},\qquad \operatorname{tg}\varphi = \frac{b_L - b_C}{g} \]

\(I_L\) кернеуден 90° қалады, \(I_C\) 90° озады, сондықтан олар бір-бірін азайтады. \(b_L \gt b_C\) болса сипат индуктивтік, \(b_L \lt b_C\) болса сыйымдылықтық, тең болса токтар резонансы.

Мысал 7. Параллель RLC

\(U = 120\) В, \(R = 30\) Ом, \(X_L = 20\) Ом, \(X_C = 40\) Ом.

  1. \(I_R = 120/30 = 4\) А, \(I_L = 120/20 = 6\) А, \(I_C = 120/40 = 3\) А.
  2. \(I = \sqrt{4^2 + (6-3)^2} = 5\) А (4 + 6 + 3 = 13 А емес).
  3. Өткізгіштіктер: \(g = 0{,}033\), \(b_L = 0{,}05\), \(b_C = 0{,}025\) См; \(y = \sqrt{0{,}033^2 + 0{,}025^2} = 0{,}042\) См. Тексеру: \(I = 120\cdot0{,}0417 = 5\) А.
  4. \(\operatorname{tg}\varphi = 3/4\), \(\varphi = 36{,}9^\circ\), сипаты индуктивтік: жалпы ток кернеуден қалады.
Есте сақта: екі қосылудың айнасы

Тізбектей: ортақ ток, кернеулер қосылады, кедергілермен есепте (\(R, X, z\)). Параллель: ортақ кернеу, токтар қосылады, өткізгіштіктермен есепте (\(g, b, y\)). Формулалар бірдей, тек әріптер ауысады.

2.9. Қуаттар: P, Q, S және қуат коэффициенті

Лездік қуат \(p = ui\) екі еселенген жиілікпен тербеледі. Оның орташа мәні активтік қуат: шынымен жылуға не жұмысқа айналатын бөлік. Қуат теріс болған аралықтарда тізбек энергияны көзге қайтарады. Осы «ары-бері» жүретін энергияны реактивтік қуат сипаттайды.

\[ P = UI\cos\varphi = I^2R\ [\text{Вт}],\qquad Q = UI\sin\varphi = I^2X\ [\text{вар}],\qquad S = UI = \sqrt{P^2 + Q^2}\ [\text{В·А}] \]
  • \(P\): активтік қуат, ватт. Тек резисторларда бөлінеді.
  • \(Q\): реактивтік қуат, вар (вольт-ампер реактивті). \(Q = Q_L - Q_C\). Индуктивтік жүктемеде оң, сыйымдылықтықта теріс.
  • \(S\): толық қуат, вольт-ампер. Генератор мен трансформатордың қуаты осымен беріледі.
  • \(\cos\varphi = P/S = R/z\): қуат коэффициенті. Толық қуаттың қандай бөлігі пайдалы екенін көрсетеді.

Комплекстік қуат: кернеу комплексі токтың түйіндес комплексіне көбейтіледі.

\[ \underline{S} = \dot U\,\overset{*}{I} = UIe^{j(\psi_u - \psi_i)} = P + jQ \]
Мысал 8. Қуаттар

Мысал 6-ның тізбегі: \(U = 100\) В, \(I = 2\) А, \(R = 30\) Ом, \(X = 40\) Ом, \(\cos\varphi = 0{,}6\), \(\sin\varphi = 0{,}8\).

  1. \(P = 100\cdot2\cdot0{,}6 = 120\) Вт. Тексеру: \(I^2R = 4\cdot30 = 120\) Вт.
  2. \(Q = 100\cdot2\cdot0{,}8 = 160\) вар. Тексеру: \(Q_L - Q_C = 4\cdot80 - 4\cdot40 = 160\) вар.
  3. \(S = 100\cdot 2 = 200\) В·А \(= \sqrt{120^2+160^2}\).
  4. Комплекс түрде: \(\dot U = 100e^{j53{,}1^\circ}\), \(\dot I = 2e^{j0^\circ}\), \(\underline{S} = 200e^{j53{,}1^\circ} = 120 + j160\) В·А.
Тесттегі тұзақ

Бірліктер: P ваттпен, Q вармен, S вольт-ампермен. Комплекстік қуатта \(\dot U\dot I\) емес, \(\dot U\overset{*}{I}\). Түйіндесті ұмытсаң, бұрыш \(\psi_u + \psi_i\) болып, жауап қате шығады.

Қуат коэффициентін жақсарту

Тұтынушыға керегі P. Бірақ желідегі ток \(I = P/(U\cos\varphi)\). \(\cos\varphi\) төмен болса, сол пайдалы қуат үшін ток үлкен болады: сымдардағы шығын (\(I^2R\)) өседі, генератор мен трансформатор толық пайдаланылмайды. Өндірістегі жүктеме негізінен индуктивтік (қозғалтқыштар), сондықтан оған параллель конденсатор қосады. Конденсатордың тогы жүктеменің реактивтік тогына қарсы бағытталып, оны өтейді (компенсациялайды). Активтік қуат өзгермейді.

\[ Q_C = P(\operatorname{tg}\varphi_1 - \operatorname{tg}\varphi_2),\qquad C = \frac{Q_C}{\omega U^2} \]

\(\varphi_1\): компенсацияға дейінгі, \(\varphi_2\): кейінгі бұрыш; \(Q_C\): конденсатор батареясының қуаты (вар).

Мысал 9. Конденсатор таңдау

Жүктеме \(P = 10\) кВт, \(U = 220\) В, \(f = 50\) Гц, \(\cos\varphi_1 = 0{,}6\). \(\cos\varphi_2 = 0{,}8\)-ге жеткізу керек.

  1. \(\operatorname{tg}\varphi_1 = 0{,}8/0{,}6 = 1{,}333\); \(\operatorname{tg}\varphi_2 = 0{,}6/0{,}8 = 0{,}75\).
  2. \(Q_C = 10(1{,}333 - 0{,}75) = 5{,}83\) квар.
  3. \(C = 5833/(314\cdot220^2) = 384\) мкФ.
  4. Желі тогы: бұрын \(I_1 = 10000/(220\cdot0{,}6) = 75{,}8\) А, кейін \(I_2 = 10000/(220\cdot0{,}8) = 56{,}8\) А. Ток 25%-ға, сымдағы шығын 44%-ға азайды.

2.10. Кернеулер резонансы (тізбектей контур)

Анықтама

Резонанс: құрамында L мен C бар тізбектің кірісіндегі ток пен кернеу фазалас болатын режим (\(\varphi = 0\)), яғни тізбек көзге таза активтік кедергі сияқты көрінеді. Тізбектей контурда ол кернеулер резонансы деп аталады.

\[ X_L = X_C\ \Rightarrow\ \omega_0 L = \frac{1}{\omega_0 C}\ \Rightarrow\ \omega_0 = \frac{1}{\sqrt{LC}},\qquad f_0 = \frac{1}{2\pi\sqrt{LC}} \]

Резонансқа жиілікті, L-ді не C-ны өзгерту арқылы жетеді. Резонанс кезінде:

  • \(X = 0\), толық кедергі ең аз: \(z = R\);
  • ток ең үлкен: \(I_0 = U/R\);
  • \(\varphi = 0\), \(\cos\varphi = 1\), \(Q = 0\), \(S = P\);
  • \(U_L = U_C\), олар қарсы фазада, бірін-бірі толық теңгереді, \(U_R = U\);
  • \(U_L\) мен \(U_C\) кіріс кернеуінен көп есе үлкен болуы мүмкін (атауы осыдан).
\[ \rho = \sqrt{\frac{L}{C}} = \omega_0 L = \frac{1}{\omega_0 C},\qquad Q = \frac{\rho}{R} = \frac{U_L}{U} = \frac{U_C}{U},\qquad d = \frac1Q \]

\(\rho\): толқындық (сипаттамалық) кедергі, резонанстағы әр реактивтік элементтің кедергісі (Ом). \(Q\): сапалылық, резонанста реактивтік элементтегі кернеу кірістегіден неше есе үлкен екенін көрсетеді (өлшемсіз; реактивтік қуат Q-мен шатастырма). \(d\): өшу.

Резонанс қисықтары және өткізу жолағы

Токтың жиілікке тәуелділігі резонанс қисығы деп аталады. Сапалылық неғұрлым жоғары болса, қисық соғұрлым үшкір, контур соғұрлым таңдағыш.

\[ \frac{I}{I_0} = \frac{1}{\sqrt{1 + Q^2\left(\dfrac{\omega}{\omega_0} - \dfrac{\omega_0}{\omega}\right)^2}} \]
\[ \Delta\omega = \omega_2 - \omega_1 = \frac{\omega_0}{Q},\qquad \Delta f = \frac{f_0}{Q} \]

Өткізу жолағы: ток \(I_0/\sqrt2 = 0{,}707 I_0\)-ден кем болмайтын жиіліктер аралығы. Оның шекараларында қуат резонанстағыдан 2 есе аз, \(|X| = R\), \(\varphi = \pm45^\circ\).

Мысал 10. Тізбектей контур

\(L = 0{,}2\) Гн, \(C = 5\) мкФ, \(R = 10\) Ом, \(U = 10\) В.

  1. \(\omega_0 = 1/\sqrt{0{,}2\cdot5\cdot10^{-6}} = 1000\) рад/с; \(f_0 = 1000/6{,}28 = 159\) Гц.
  2. \(\rho = \sqrt{0{,}2/(5\cdot10^{-6})} = 200\) Ом (тексеру: \(\omega_0L = 1000\cdot0{,}2 = 200\) Ом).
  3. \(Q = 200/10 = 20\).
  4. \(I_0 = 10/10 = 1\) А. \(U_L = U_C = 1\cdot200 = 200\) В \(= QU\). Кірісте 10 В қана!
  5. Өткізу жолағы: \(\Delta\omega = 1000/20 = 50\) рад/с, \(\Delta f = 159/20 \approx 8\) Гц.

2.11. Токтар резонансы (параллель контур)

L мен C параллель қосылғанда резонанс шарты реактивтік өткізгіштіктердің теңдігі:

\[ b_L = b_C;\qquad \text{идеал контур үшін}\ \ \frac{1}{\omega_0 L} = \omega_0 C\ \Rightarrow\ \omega_0 = \frac{1}{\sqrt{LC}} \]

Резонанс кезінде:

  • толық өткізгіштік ең аз (\(y = g\)), яғни контурдың кедергісі ең үлкен;
  • тармақталмаған бөліктегі (көзден келетін) ток ең аз: \(I = Ug\);
  • \(I_L = I_C\), олар қарсы фазада, контур ішінде айналып жүреді және жалпы токтан көп есе үлкен болуы мүмкін (атауы осыдан);
  • \(\varphi = 0\), \(\cos\varphi = 1\);
  • шығыны жоқ идеал контурда (\(g = 0\)) жалпы ток нөл, кедергісі шексіз.

R, L, C үшеуі параллель контурдың сапалылығы \(Q = I_L/I = R/\rho\) (тізбектей контурдағы \(\rho/R\)-ге кері).

\[ \omega_0' = \frac{1}{\sqrt{LC}}\sqrt{1 - \frac{R^2}{\rho^2}},\qquad R_{\text{рез}} \approx \frac{\rho^2}{R} = \frac{L}{CR} \]

2.12. Индуктивті байланысқан элементтер

Екі орауыш жақын тұрса, біреуінің магнит ағынының бір бөлігі екіншісін де қиып өтеді. Бірінші орауыштағы ток өзгергенде екіншісінде ЭҚК пайда болады. Бұл өзара индукция, ал оның өлшемі өзара индуктивтілік \(M\) (Гн).

\[ e_{2M} = -M\frac{di_1}{dt},\qquad \dot U_{2M} = j\omega M\,\dot I_1,\qquad X_M = \omega M \]
\[ k = \frac{M}{\sqrt{L_1L_2}},\qquad 0 \le k \le 1 \]

\(k\): байланыс коэффициенті. \(k = 0\): байланыс жоқ. \(k = 1\): бүкіл ағын екі орауышты да қамтиды (идеал жағдай). Демек \(M\) ешқашан \(\sqrt{L_1L_2}\)-ден аспайды.

Аттас қысқыштар, келісілген және қарсы қосу

Өзара индукция ағыны өз ағынын күшейте ме, әлсірете ме, ол орамалардың орау бағытына байланысты. Оны сұлбада нүктемен (не жұлдызшамен) белгілейді. Аттас қысқыштар: токтар оларға қатысты бірдей бағытталса (екеуінде де нүктеге кірсе), өзіндік және өзара индукция ағындары қосылады.

  • Келісілген қосу: токтар аттас қысқыштарға бірдей кіреді, ағындар қосылады.
  • Қарсы қосу: бір орауышта ток нүктеге кіреді, екіншісінде нүктеден шығады, ағындар азайтылады.
\[ L_{\text{кел}} = L_1 + L_2 + 2M,\qquad L_{\text{қар}} = L_1 + L_2 - 2M,\qquad M = \frac{L_{\text{кел}} - L_{\text{қар}}}{4} \]

Соңғы формула \(M\)-ді тәжірибеден анықтауға қолданылады: орауыштарды екі тәсілмен қосып, баламалы индуктивтілікті өлшейді. Қай қосуда ток аз (кедергі үлкен) болса, сол келісілген. Комплекс түрде тізбектей қосылған екі орауыш үшін: \(\dot U = [R_1 + R_2 + j\omega(L_1 + L_2 \pm 2M)]\dot I\).

  2. Келісілген: \(L = 0{,}4 + 0{,}1 + 0{,}3 = 0{,}8\) Гн. Қарсы: \(L = 0{,}5 - 0{,}3 = 0{,}2\) Гн.

Ауа трансформаторы (болат өзексіз трансформатор)

Тек магнит өрісі арқылы байланысқан екі орауыш. Біріншісі көзге, екіншісі жүктемеге қосылады. Болат өзегі жоқ, сондықтан ол сызықты элемент. Энергия бірінші орамадан екіншісіне өзара индукция арқылы беріледі.

\[ \dot U_1 = (R_1 + j\omega L_1)\dot I_1 - j\omega M\dot I_2,\qquad 0 = (R_2 + j\omega L_2 + \underline{Z}_{\text{ж}})\dot I_2 - j\omega M\dot I_1 \]

Екінші теңдеуден \(\dot I_2\)-ні тауып, біріншіге қойсақ, екінші контурдың бірінші контурға әсері қосымша кедергі ретінде көрінеді. Ол енгізілген кедергі деп аталады:

\[ \underline{Z}_{\text{кір}} = R_1 + j\omega L_1 + \underline{Z}_{\text{ен}},\qquad \underline{Z}_{\text{ен}} = \frac{(\omega M)^2}{\underline{Z}_{22}},\quad \underline{Z}_{22} = R_2 + j\omega L_2 + \underline{Z}_{\text{ж}} \]
Мысал 13

\(\omega M = 50\) Ом, екінші контурдың толық кедергісі \(\underline{Z}_{22} = 30 + j40\) Ом.

\(\underline{Z}_{\text{ен}} = 2500/(30 + j40) = 2500(30 - j40)/2500 = 30 - j40\) Ом. Енгізілген активтік кедергі оң (30 Ом: екінші контур энергия тұтынады), ал реактивтік бөлігінің таңбасы кері: екінші контурдың индуктивтік кедергісі бірінші контурға сыйымдылықтық болып енеді, яғни оның индуктивтік кедергісін азайтады.

Өзіңді тексер: u = 141 sin(628t + 20°) В, i = 2,82 sin(628t + 50°) А. f, U, I, φ және сипаты?

f = 628/6,28 = 100 Гц. U = 100 В, I = 2 А. φ = 20° − 50° = −30°: ток озады, сипаты активтік-сыйымдылықтық. P = 100·2·cos 30° = 173 Вт.

Өзіңді тексер: тізбектей R мен L-дегі вольтметрлер 30 В және 40 В көрсетеді. Кірістегі кернеу?

√(30² + 40²) = 50 В. Арифметикалық қосынды 70 В қате, себебі кернеулер 90° ығысқан.

Өзіңді тексер: тізбектей контурда жиілікті резонанстық жиіліктен жоғары көтерсек, сипаты қандай болады?

XL өседі, XC кемиді, X оң болады: сипаты индуктивтік, ток кернеуден қалады. Жиілік резонанстықтан төмен болса, керісінше сыйымдылықтық.

Өзіңді тексер: L = 0,1 Гн, ω = 1000 рад/с. Резонанс үшін қандай C керек?

C = 1/(ω²L) = 1/(10⁶·0,1) = 10⁻⁵ Ф = 10 мкФ.

Өзіңді тексер: келісілген қосуда 1,2 Гн, қарсы қосуда 0,4 Гн өлшенді. M?

M = (1,2 − 0,4)/4 = 0,2 Гн.
